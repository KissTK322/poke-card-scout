# Poke Card Scout

ระบบช่วยเลือกซื้อการ์ดโปเกมอน ทั้งใบดิบและใบเกรด (PSA, BGS Black Label, CGC, TAG, SQC, PCG ฯลฯ) ภาษา EN / JP / TH

**เปิดใช้งาน:** https://kisstk322.github.io/poke-card-scout/

## ทำอะไรได้บ้าง
- **แนะนำ** — การ์ดที่น่าเก็บ พร้อมรูปและราคาตลาดสด (EN) กรองตามหมวด (Blue-chip / วินเทจ / Mega 2026 / ญี่ปุ่น / ไทย / งบน้อย), ภาษา และงบ
- **ค้นหา** — ค้นการ์ดทุกใบจากฐานข้อมูล TCGdex ได้ทั้งชื่อ EN, ญี่ปุ่น, ไทย ดูรูป ราคา แล้วกด "ประเมินใบนี้"
- **ประเมิน / ใส่รูป** — ใส่รูปกรอบเกรด → ลากกรอบครอบป้าย → ระบบอ่านชื่อ/ภาษา/เกรดให้ กรอกราคาที่ขายได้จริง + ราคาประมูลตอนนี้ แล้วได้ **คะแนน 0–100** กับ **ราคาที่ควรประมูลไม่เกิน**
- **ที่บันทึกไว้** — เก็บผลประเมินไว้ในเครื่อง (localStorage ของเบราว์เซอร์)

## ปรับตัวเลข
ค่าทั้งหมด (ค่า k ของเจ้าเกรด, น้ำหนักคะแนน, รายการการ์ดแนะนำ) อยู่ใน `js/data.js` สูตรอยู่ใน `js/scoring.js`

## หมายเหตุ
- ราคา JP/TH ในฐานข้อมูลยังเป็นราคาเวอร์ชัน EN ให้เช็กราคาขายจริงจาก eBay sold, PriceCharting, SNKRDUNK, TCG Thailand
- เป็นเครื่องมือช่วยตัดสินใจ ไม่ใช่คำแนะนำการลงทุน

ข้อมูลการ์ด: [TCGdex](https://tcgdex.dev) · อ่านรูป: [Tesseract.js](https://tesseract.projectnaptha.com) · ชื่อโปเกมอน: [PokeAPI](https://pokeapi.co)
